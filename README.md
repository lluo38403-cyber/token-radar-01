Token Radar (model radar-2): a dashboard that ranks the pre-token protocols in the DefiLlama snapshot of 2026-11-14 by implied value — 40 watchlist protocols plus 138 genuine launch candidates below the $50M floor — and gives each one a six-step farm plan with costs and times. Implied value follows only from the snapshot's figures: TVL, seven-day growth, age with no token, and how many chains the protocol runs on. Live-token protocols are set aside with their market caps shown, never mixed into the ranking.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
